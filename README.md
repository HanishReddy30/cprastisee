# C/LAB

C/LAB is a browser-based practice studio for 50 beginner C programming exercises. Students can browse by topic, search the library, inspect starter code, reveal hints or solutions, and mark exercises complete. Completion state is saved in the browser with `localStorage`.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. The production build can be checked with:

```bash
npm run build
```

## Exercise coverage

- Basics and input/output
- If statements and else-if ladders
- Switch statements
- Number algorithms
- Fibonacci and other series
- Pattern printing

The project is a Vite + React + TypeScript frontend and does not require a backend.
